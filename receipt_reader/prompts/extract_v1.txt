Rules:
- Dates must be YYYY-MM-DD. If the format is ambiguous (03/04), keep raw_text and set confidence to low.
- Amounts are numbers without currency symbols. total is the final amount paid (after tax and tip). If the tip is handwritten, confidence is medium or low.
- Currency is an ISO code. If only "$" is shown with no country hint, use USD with medium confidence.
- payment_last4 is the last 4 digits only. Never return a full card number.
- is_alcohol is true for beer, wine, spirits, cocktails, and brand names like Heineken.
- alcohol_detected is true if any line item is alcohol or the receipt is clearly from a bar selling drinks.
- If you see more than one candidate total (before/after tip), set multiple_totals true, list candidates, and put the final paid amount in total.
- If more than one receipt is in the file, set multi_receipt true.
